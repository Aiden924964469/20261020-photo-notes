# 数字恋爱博物馆 · 自包含明文版（无密码 / 无加密）

单文件 `index.html`，**所有照片缩略图与 2 段视频已内联为 base64**，**不依赖任何外部文件、不需要密码、没有加密门禁**。

## 怎么打开

### A. 本地直接看
直接**双击 `index.html`** 即可（资源已内联，file:// 也能正常显示照片墙、展厅和视频）。
若你的浏览器对本地视频有限制，可双击 `start_local.bat` 起一个本地服务再访问 `http://localhost:8080`。

### B. 上传到服务器 / GitHub Pages
把本文件夹里的 `index.html`（以及 `.nojekyll`）放到**仓库根目录**，开启 Pages 后用 `https://<用户名>.github.io/<仓库名>/` 打开即可。
因为是完全自包含的单文件，服务器上只需这一个文件，照片即开即看，**无需输入任何密码**。

## 上传到 GitHub

1. 新建（或打开）一个 GitHub 仓库。
2. 把 `index.html` 与 `.nojekyll` 放到仓库根目录。
3. 仓库 **Settings → Pages → Source** 选择对应分支与根目录，保存。
4. 等待 1–2 分钟，访问 Pages 链接即可观看。
